Authentication Required

All endpoints (except GET /health) require a valid Supabase JWT. On the frontend, call supabase.auth.getSession() after Google OAuth and include the token as Authorization: Bearer <token> on every request. Click Authorize in the Swagger UI below to set your token for live testing.
